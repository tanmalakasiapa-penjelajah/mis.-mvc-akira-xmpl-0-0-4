1. TUGAS HARI INI
--------------------------------------------------------------------------------
a. Audit perilaku soft-delete ("Sampah") di seluruh tabel.
b. Membangun halaman khusus "Sampah" sebagai satu tempat melihat semua data
   soft-deleted, dipecah per tabel (tab), dengan aksi Pulihkan (restore)
   dan Hapus Selamanya (permanent).
c. Melengkapi CRUD (Tambah + Ubah) untuk semua tabel di halaman biasa,
   termasuk preview modal (Lihat), dengan penghapusan yang masuk keranjang
   sampah (soft-delete), bukan hapus permanen.
d. Menyelaraskan frontend agar cocok dengan pola request `[FromBody] string`
   backend (code dikirim sebagai STRING JSON, bukan objek {"code": ...}).

2. YANG SUDAH DIKERJAKAN
--------------------------------------------------------------------------------
### Backend (Shared / Read / Write)

  BacaService.cs  (src/MvcAkira.Shared/Services/)
    - Tambah method query untuk data sampah:
        TrashJabatan, TrashTarget, TrashPengguna, TrashBiodata,
        TrashHakakses, TrashKeuangan
      (TrashToko untuk meja_toko sudah ada sejak sebelumnya).
    - Semua query menerima ListQuery (page/limit/search dll) dan hasil
      PageResult<T> — sama seperti list aktif.

  ReadController.cs  (src/MvcAkira.Read/Controllers/)
    - Menambah endpoint GET untuk tiap tabel:
        GET /api/meja_toko/trash        (sudah ada)
        GET /api/meja_jabatan/trash
        GET /api/meja_target/trash
        GET /api/meja_pengguna/trash
        GET /api/meja_biodata/trash
        GET /api/meja_hakakses/trash
        GET /api/meja_keuangan/trash
    - Semua dilindungi otorisasi via BacaService.CekBacaAsync.

  TulisService.cs  (src/MvcAkira.Shared/Services/)
    - Menambah operasi CRUD yang sebelumnya TIDAK ada:
        CreatePenggunaAsync   — buat akun baru (hash password)
        UpdatePenggunaAsync   — ubah email + flag nonaktif
        UpdateJabatanAsync    — ubah nama jabatan
        UpdateTargetAsync     — ubah nama + keterangan
        UpdateBiodataAsync    — ubah nama/born/address/phone
    - Menambah operasi sampah untuk pengguna dan hak akses:
        SoftDeletePenggunaAsync / RestorePenggunaAsync / PermanentPenggunaAsync
        SoftDeleteHakaksesAsync / RestoreHakaksesAsync / PermanentHakaksesAsync
    - Guard ANTI_ORPHAN: pengguna yang masih memiliki meja_hakakses AKTIF
      TIDAK BOLEH di-soft-delete (ditolak 409). Saat dilepas, pengguna juga
      diset PenggunaNonaktif=1.
    - Catatan: meja_log TIDAK punya sampah (read-only) karena merupakan
      catatan audit.

  WriteController.cs  (src/MvcAkira.Write/Controllers/WriteController.cs)
    - Route tambahan (semua [Authorize]):
        PUT  /api/meja_jabatan        (update)
        POST & PUT /api/meja_pengguna (create/update)
        PUT  /api/meja_target         (update)
        PUT  /api/meja_biodata        (update)
        POST /api/meja_pengguna/restore
        DELETE /api/meja_pengguna/permanent
        POST /api/meja_hakakses/restore
        DELETE /api/meja_hakakses/permanent
    - record body baru: JabatanBody, TargetBody, PenggunaBody, BiodataBody.
