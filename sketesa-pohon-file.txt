KEGUNAAN TIAP FILE — POIN PENTING (ringkas)
================================================================================
  SlNx            ~ definisi solusi (referensi 5 proyek + test).
  run*.sh         ~ jalankan/hentikan semua service; stop mematikan semua.
  DbPath.cs       ~ kunci: menemukan file DB yang SAMA walau 4 proyek berbeda.
  BacaService.cs  ~ SEMUA query (list + detail + trash + dashboard).
  TulisService.cs ~ SEMUA penulisan (create/update/soft/restore/permanent).
  ApiExceptionMiddleware → respons error 4xx yang ramah ({error,message}).
  OtoritasService.cs → cek hak akses (BolehBaca/BolehTulis) + isolasi toko.
  LogService.cs    → tiap aksi tulis otomatis masuk meja_log.
  CodeGenerator.cs  → pembuat kode unik utk semua tabel.
  app.js / config.js   → "otak" SPA, termasuk halaman sampah baru.
  api.js               → akses endpoint + token.
